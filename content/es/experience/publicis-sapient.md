Trabajé como Ingeniero DevOps diseñando e implementando infraestructura en la nube AWS para una migración de base de datos heredada a gran escala.

## Logros
1. Diseñé una arquitectura AWS multi-AZ para una migración de base de datos heredada a gran escala, garantizando alta disponibilidad y resiliencia con RDS PostgreSQL, ElastiCache, KMS, Secrets Manager, Lambda y EventBridge, cumpliendo con los estándares HIPAA.
2. Implementé toda la infraestructura como código con Terraform, desplegando en múltiples entornos mediante pipelines de CI/CD con GitHub Actions.
3. Validé políticas IAM extensas para habilitar el aprovisionamiento seguro de recursos en Glue, SQS, SNS, EC2 y otros servicios de AWS.
